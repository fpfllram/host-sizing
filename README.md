## 建站主机到底该买多大

买小了跑不动，买大了每个月多花钱还闲着。判断依据有两个：你的站跑什么程序，预期有多少访问量。

| 站点类型 | CPU / 内存 | 系统盘 | 带宽 | 说明 |
| --- | --- | --- | --- | --- |
| 静态站、轻量 CMS | 1核 / 1G | 20–40G | 1–3M | 程序本身吃不了多少内存 |
| WordPress 个人博客 | 1–2核 / 2G | 40G | 3M | 2G 是跑 WP 比较舒服的线 |
| 企业官网（图片不多） | 2核 / 2–4G | 40–60G | 3–5M | 留出后台操作和并发余量 |
| WooCommerce、多站点 | 2–4核 / 4G 起 | 60G+ | 5M | 数据库和插件一起吃内存 |
| 外贸独立站、有推广流量 | 4核 / 4–8G | 80G+ | 5M 起 | 按峰值估，不按日常估 |

这张表是经验值，不是硬规定。云服务器可以随时升配，新手起步宁可小一档，跑起来再扩，比一上来买大浪费钱划算。

网上两份流传较广的教程口径不太一样。一份按站点类型分档，认为个人博客 512MB 到 1GB 就够；另一份从“面板 + 数据库 + 网站程序”的整体负载出发，认为 1核1G 跑得很勉强，2核2G 才算稳妥起步。两边其实不矛盾：前者说的是程序本身要吃多少，后者算的是你装完宝塔、MySQL 和 PHP 之后整台机器的占用。按后者准备更保险，因为绝大多数人不会只跑一个裸程序。

## 内存先撞墙，CPU 很少是瓶颈

WordPress 裸装大概吃 200MB 内存。装上 WooCommerce、两三个缓存插件、再挂上定时任务，1GB 就开始紧张。

1G 内存的机器在流量稍有波动时，最容易发生的是 OOM：进程被系统直接杀掉。用户看到的是网站突然 502，SSH 还能连上，重启一下又恢复正常。这类问题排查起来很费时间，日志里往往只留一行 killed。

所以内存这一项不建议省。CPU 核心数反而没那么关键，建站程序大多是单线程敏感型，PHP 执行和数据库查询看的是单核性能，不是核心数量。预算有限时，把钱加在内存上比加在核数上更容易感觉到差别。

## 国内机房还是香港机房

国内机房的好处是延迟低，同省访问常常是个位数毫秒。代价是域名必须完成 ICP 备案才能通过域名访问，这是法规要求，不是技术限制。备案通过服务商提交，周期通常 10 到 20 个工作日，中间要准备主体资料、做核验拍照，个人备案和企业备案要的材料还不一样。

境外机房免备案，机器开出来解析一条 A 记录就能访问。延迟方面，香港到国内主要城市通常在 10 到 50ms，美西在 140 到 180ms。这个差距对纯文字页面影响不大，对图片多、交互多的站就有体感差别。

具体怎么选：

- 客户主要是国内企业，站点用来放公司介绍和联系方式：国内机房加备案，速度优先
- 个人博客、技术笔记，不想折腾备案：香港机房
- 外贸站、客户在欧美：直接选对应地区的机房，别让客户绕半个地球访问
- 赶时间上线做活动：境外机房，当天就能用

香港节点的带宽成本比内地高。标着 CN2 GIA 这类优化线路的香港入门套餐，海外商家公开标价常见在每月 30 美元以上。这笔钱要提前算进预算。

## 带宽和系统盘，两个最容易被低估的项

1M 带宽能不能用？纯文字博客勉强可以，但后台操作会有明显等待感，发文章点保存要转两秒。图片稍多的站建议 3M 起。

带宽按固定值购买，超出后不额外扣费，会限速。这一点对成本控制是好事，至少不会收到一张意外账单，代价是流量高峰时页面会变慢。

系统盘 40G 是起步线。面板本身占不了多少，真正吃盘的是网站文件、数据库和日志，再加上历次备份。一个更新正常的 WordPress 站，跑半年到一年，40G 就有见底的风险，尤其是开了定时备份、备份还都存在本地的时候。服务商支持在线扩容，可以先买 40G 后加；不支持扩容的，直接上 60G 或 80G 更省事。

## 计费周期：年付省下的钱，可能第二年就还回去

年付普遍比月付便宜，但下单前要确认两件事：续费价是多少，配置能不能中途升。

有些优惠只作用于第一个周期，第二年按原价续，两年算下来的总成本比一直月付还高。这个差价在购买页不一定写得显眼，通常藏在活动规则或者订单页的小字里。

第一次用某家服务器，先月付更稳。跑两周，看后台响应速度、看晚高峰会不会卡、看监控里的内存曲线，确认没问题再转年付。省下的那点折扣，不值得用一次搬家来换。

## 服务器到手到网站能打开，中间还有五步

买完服务器不等于网站就能访问。下面这几步大部分教程会讲，但顺序和容易漏的点值得单独拎出来。

1. **先放行端口，再装面板。** 云服务商的安全组是独立于服务器内部防火墙的一层过滤。面板默认用 8888 端口，网站要 80 和 443。只放行 SSH 的 22，面板装完也打不开。在安全组入方向规则里把这三个端口都加上，协议选 TCP。
2. **系统选纯净的。** 宝塔这类面板要求环境里没有预装 Nginx、Apache、MySQL、PHP，否则安装脚本会因为端口或依赖冲突失败。购买时选“纯净系统”或最小化安装镜像。
3. **操作系统选 Debian 12 或 Ubuntu 22。** 面板官方给出的兼容性排序是 Debian 12 优于 Ubuntu 22，Ubuntu 22 优于 CentOS 9。CentOS 7 已经停止维护，新机器不建议再选。
4. **装完面板选 LNMP。** Nginx + MySQL + PHP 在并发处理上比 LAMP 好，多数场景默认选这个。PHP 版本按程序要求来，WordPress 建议 7.4 或 8.0 以上。
5. **域名解析加 A 记录，然后申请 SSL。** 主机记录填 `@` 是裸域名，填 `www` 是子域名，记录值填服务器公网 IP，生效几分钟到半小时。面板里能直接申请 Let's Encrypt 免费证书，自动续期，上线就开 HTTPS。

上线前还有三件事容易被跳过。伪静态规则要在站点设置里选对应程序并保存，不然文章页链接会带一堆参数。确认根目录的默认首页文件已经被程序覆盖，否则访问域名看到的还是面板生成的静态页。计划任务里开定时备份，保留最近 3 份就够，份数设多了磁盘会被旧备份吃满。

## 有些情况不需要买云服务器

日访问个位数、纯做技术验证、只想跑个 demo，这类需求买一台正经云服务器有点浪费。

免费方案确实存在。比如 Serv00 提供有效期长达 10 年的免费 VPS，邮箱注册就能申请，3G 空间、512M 内存。限制要提前知道：没有 root 权限，SSH 登录后只能在 `/home/用户名` 目录下操作，性能也不稳定，观察中 CPU 会无故占用到 100%，本质是多人共享一台机器。它适合放一个静态个人主页、做开发测试，不适合放企业站，也不适合跑 WordPress 这种吃内存的程序。

企业站、有订单转化的站，别在主机上省钱。一次宕机导致的客户流失，够买好几年服务器。

## 下单前最后确认这几件事

- **退款和试用**：有没有几天无理由退款，条件是什么，比如流量用了多少就不给退。第一次用某家，这条比价格重要。
- **续费价**：活动价管多久，之后按什么价续。
- **能不能升配**：后期加内存、加硬盘是不是在线点几下就行，还是要重装迁移。
- **带宽超出怎么处理**：限速还是按量计费，两者成本差别很大。
- **备份策略**：商家提供快照，还是要自己在面板里设定时任务。异地备份比同机备份可靠。

最后给一组选择规则，对着自己的情况挑一条：

- 只放静态页或轻量 CMS，访问量不大：1核1G，配置到此为止
- WordPress 个人博客、小企业展示站：2核2G，系统盘 40G 起
- 要跑商城、放多个站点：2核4G 或 4核4G，系统盘 60G 起
- 客户在国内、对速度有要求：国内机房，预留 10 到 20 个工作日做备案
- 不想备案，或者客户在海外：香港等境外机房
- 只是测试、验证想法：先用免费方案，确认要长期做再买
